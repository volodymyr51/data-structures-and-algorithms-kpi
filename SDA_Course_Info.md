# Структури даних та алгоритми (СДА)
## Загальна інформація про виконання лабораторних робіт курсу

Ця інформація стосується всіх 5 лабораторних робіт курсу і наведена тут один раз. Кожен окремий документ лабораторної роботи посилається сюди замість того, щоб повторювати цей розділ.

---

## 1. Мова програмування

Усі лабораторні роботи виконуються мовою **С** (не С++ і не будь-яка інша мова).

## 2. Перелік лабораторних робіт

| № | Назва |
|---|---|
| 1 | Розгалужені алгоритми |
| 2 | Алгоритми з вкладеними циклами та метод динамічного програмування |
| 3 | Стеки та черги |
| 4 | Алгоритми двійкового пошуку |
| 5 | Алгоритми сортування |

> Конкретні дати захисту та терміни здачі кожної роботи узгоджуйте безпосередньо з викладачем.

## 3. Система оцінювання

- Загальна сума балів за всі 5 лабораторних робіт: **мінімум 32, максимум 60 балів**.
- Кожна окремо взята лабораторна робота, яка зарахована («пройдена»), оцінюється від **6 до 12 балів**.
- Бали знижуються за помилки в оформленні звіту (див. розділ «Вимоги до оформлення звіту» в кожній роботі) та за неправильні відповіді на контрольні питання.
- За несвоєчасну (пізню) здачу лабораторної роботи знімається **1 бал** — тобто максимум за пізню здачу становить 11 балів (максимум 12 балів можна отримати лише за вчасну здачу відносно терміну, встановленого викладачем).
- Лабораторна робота — це невеличке дослідження. Результати мають бути грамотно оформлені та містити змістовні висновки, написані самостійно, а **не згенеровані штучним інтелектом** (очікується власний, а не «шаблонний» стиль викладу).

## 4. Середовище розробки (IDE)

Дозволяється використовувати будь-яку зручну IDE — головна вимога незмінна: мова програмування має бути **С** (не С++ і не будь-яка інша мова).

### Основні (рекомендовані) варіанти

#### Visual Studio Code (VS Code)
Легкий, кросплатформний і безкоштовний редактор (Windows, Linux, macOS) — гарний варіант, якщо не потрібне повноцінне середовище на кшталт Code::Blocks.

1. Завантажити й встановити VS Code: <https://code.visualstudio.com/>
2. Встановити компілятор C, якщо його ще немає:
   - **Windows:** встановити MinGW-w64 — найпростіше через **MSYS2** (<https://www.msys2.org/>), а потім у терміналі MSYS2 виконати `pacman -S mingw-w64-ucrt-x86_64-gcc`. Альтернатива — окремий інсталятор MinGW (див. інструкцію в розділі про Code::Blocks нижче).
   - **Linux:** `sudo apt-get install build-essential` (містить `gcc`).
   - **macOS:** встановити Command Line Tools: `xcode-select --install` (дає компілятор `clang`, який відгукується і на виклик `gcc`).
3. У VS Code встановити розширення **C/C++** від Microsoft (`ms-vscode.cpptools`) з панелі розширень (Extensions, `Ctrl+Shift+X`) — дає підсвітку синтаксису, автодоповнення та підказки.
4. **Компіляція і запуск** — найпростіше через вбудований термінал (меню Terminal → New Terminal):
   ```
   gcc -Wall lab.c -o lab
   ./lab
   ```
   (на Windows — `lab.exe` замість `lab`). За бажанням можна налаштувати збірку по клавіші `Ctrl+Shift+B` через файл `tasks.json` — офіційний гід: <https://code.visualstudio.com/docs/languages/cpp>.

#### Code::Blocks
- Платформа: Windows, Linux, Mac OS X. Ліцензія: free.
- Інсталятор: <http://www.codeblocks.org/downloads/binaries>
- Для Windows спочатку треба встановити пакет **MinGW**, а вже потім Code::Blocks. Є пакет, що містить одразу MinGW + Code::Blocks (`codeblocks-17.12mingw-setup.exe`), але іноді з ним виникають проблеми — тоді краще перевстановити кожне окремо.
  - MinGW: <https://osdn.net/projects/mingw/downloads/68260/mingw-get-setup.exe/>
  - Інструкція зі встановлення MinGW: <http://www.codebind.com/cprogramming/install-mingw-windows-10-gcc/>
  - Детальна інструкція з ілюстраціями для Windows: <http://cppstudio.com/uk/post/2650/>
  - Інструкція з ілюстраціями для Mac OS: <https://www.technobyte.org/install-code-blocks-on-mac-os-gcc-compiler/>
- Для Debian/Ubuntu Code::Blocks є у стандартному репозиторії:
  ```
  sudo apt-get update
  sudo apt-get install codeblocks
  ```

#### Термінал (консоль) + текстовий редактор

**Linux:** встановити компілятор `gcc`: `sudo apt-get install gcc`

**Windows:** встановити MinGW (посилання вище) — у складі MinGW є `gcc`.

**Як працювати (однаково для Linux і Windows+MinGW):**

1. Пишете текст програми в будь-якому текстовому редакторі з підсвіткою коду (наприклад, Notepad++ для Windows; Gedit/Kate/Vim/Emacs для Linux).
2. Зберігаєте файл як `filename.c` (наприклад, `lab1.c`) — стандартне розширення файлів з кодом мовою С.
3. **Компіляція.** У терміналі (у Windows — `cmd.exe`), перейшовши у папку з файлом:
   ```
   gcc myfile.c -o myfile
   ```
   У Windows бінарник варто називати з розширенням `.exe`:
   ```
   gcc lab1.c -o lab1.exe
   ```
   Варто завжди використовувати опцію `-Wall`, яка вмикає показ усіх попереджень компілятора:
   ```
   gcc -Wall myfile.c -o myfile
   ```
   Якщо компіляція пройшла без попереджень і помилок — програма скомпільована успішно. Якщо є помилки — виправте їх у файлі й скомпілюйте знову.
4. **Запуск.**
   - Windows: подвійний клік по exe-файлу, або в консолі ввести ім'я файлу й натиснути Enter.
   - Linux: у терміналі в тій самій директорії виконати `./lab1`.
